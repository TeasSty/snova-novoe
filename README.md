# СНОВА НОВОЕ — сайт мастерской

Гибридная концепция: **паспорт предмета** + глава **«Город»**.

## Запуск

```bash
cd web
npm install
npm run dev
```

Сборка: `npm run build`

## Контент

Тексты — из публичных источников (VK, 59.ru и др.). Фото в `public/images` сейчас — временные арт-директ плейсхолдеры; перед публикацией заменить на реальные кадры мастерской из VK / архива.
